# 报告主索引

## 报告简报

- 主题：大模型训练与推理中的 AI Infra 基础
- 目标听众：主要面向从事大模型训练与数据工作的同事；对 AI Infra 只有基础了解。
- 分享时长：最终控制在 30–60 分钟；准备阶段可先按接近 60 分钟的完整版本组织，再根据现场需要压缩。
- 首要场景：现场演讲
- 听众收获：浏览大模型训推过程中的 Infra 基础，形成可用于理解后续章节的整体认知；具体承诺待确认
- 范围与边界：实例讲解尽量基于团队当前分析模型 MiniMax H3，并使用经典 LLM 作为对照；当前 LLM 对照暂定 Qwen3-32B，完整章节范围待确认
- 交付形态：逐页演示的单文件 HTML，并提供连续打印降级

## 贯穿案例原则

- **MiniMax H3**：团队当前正在分析的模型，是全篇实例讲解的主要参考对象；适合时优先用它把 Infra 概念落到团队实际场景。
- **经典 LLM 对照**：用于对比视频生成模型与常见 LLM 的 Infra 特征，当前选用 Qwen3-32B。
- Qwen3-32B 不是固定选择；如果存在更适合讲解的经典 LLM，可以直接替换，不限定模型系列。
- 替换经典 LLM 对照时，需要同步检查所有大纲、正文、视觉需求和资料映射。
