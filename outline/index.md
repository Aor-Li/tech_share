# 报告主索引

## 报告简报

- 主题：大模型训练与推理中的 AI Infra 基础
- 目标听众：主要面向从事大模型训练与数据工作的同事；对 AI Infra 只有基础了解。
- 分享时长：最终控制在 30–60 分钟；准备阶段可先按接近 60 分钟的完整版本组织，再根据现场需要压缩。
- 首要场景：现场演讲
- 听众收获：理解模型结构与工作负载如何转化为算力、显存和通信约束，建立阅读后续 Infra 指标与方案取舍所需的基础框架。
- 范围与边界：实例讲解尽量基于团队当前分析模型 MiniMax H3，并使用 Qwen3-32B 作为经典 dense LLM 对照；总览只建立知识地图与案例角色，不提前展开各章细节，完整章节范围仍待逐章确认。
- 交付形态：逐页演示的单文件 HTML，并提供连续打印降级

## 贯穿案例原则

- **MiniMax H3**：团队当前正在分析的模型，是全篇实例讲解的主要参考对象；适合时优先用它把 Infra 概念落到团队实际场景。
- **经典 LLM 对照**：使用 Qwen3-32B 对比视频生成模型与常见 dense LLM 的 Infra 特征；选择依据是规模合适、结构典型且型号较新，不将其表述为 Qwen 最新模型。
- **公开 Infra 案例来源**：OLMo 2 32B 不作为第三个贯穿案例，只在 MFU、集群、并行、checkpoint 和网络拓扑等内容中提供公开事实与图表参考。
- 若后续章节目标发生变化、Qwen3-32B 不再适合讲解，替换时需要同步检查所有大纲、正文、视觉需求和资料映射。
