第一章 · 计算

FLOPs → 精度 → 峰值 → MFU

0. 本章定位

如何分析一次大模型输出需要多少算力？

① 要算多少次浮点运算（FLOPs）② 用什么数据格式算（精度）③ 机器一秒能算多少（峰值）④ 实际能拿到多少（MFU）。

1.1.1 基本概念

一次浮点乘法或加法各计 1 FLOP。乘加（MAC）= 2 FLOPs。

1.1.2 基本思路

Transformer 里 95%+ 的浮点运算集中在少数 GEMM 上，「数 FLOPs」≈「数矩阵乘」。

[m,k] × [k,n] 的 GEMM = 2mkn FLOPs（乘、加各算一次）。

1.1.3 Dense Transformer

每 token 前向 ≈ 2N。反向再算 dW 与 dX，训练 C ≈ 6ND。

单层（hidden = h，MHA，FFN 扩张 4、两矩阵）：QKVO ≈ 4h²，MLP ≈ 8h²，合计 ≈ 12h²。SwiGLU 是三矩阵，同样扩张比下 MLP ≈ 12h²。

注意力分数随 s²，与参数量无关。前向 attn / linear ≈ s/(6h)。s≈4K、h≈4K 时约 0.17。

1.1.4 Qwen3-32B

规格见总览。对 2N / 6ND 的调整：

N 用实算，不套 12h²

Q 维 8,192≠h，SwiGLU、intermediate=5h。单层 ≈487.6M ×64 = 31.2B（官方非 embed）。 每 token 前向 N≈32.0B → 64 GFLOPs。

分数按 d_q 计

d_q=8,192。短对话分数项仍远小于线性；YaRN 131K 时分数项超过线性投影。

1.1.5 MiniMax H3 DiT

规格见总览。对 2N / 6ND 的调整：

2N 用 N_eff

AdaLN ≈13B 不参与逐 token。N_eff≈20B → 每 token ≈40 GFLOPs，不是 66。

6ND 不乘步数

训练时 AdaLN 要算梯度；扩散训练每样本通常只采一个 timestep。

attn / linear（s/(6h)）约 0.94～10。同一公式，谁先越过 6h，谁的账先变。

1.2.1 精度体系

BF16 用精度换动态范围（与 FP32 同指数宽），训练通常不需要 loss scaling。

混合精度：FP32 主权重 + BF16/FP16 计算 + FP32 累加。FP8 必须配 scaling。

1.2.2 Qwen3

默认 BF16

官方 torch_dtype: bfloat16。

官方 FP8

Qwen3-32B-FP8，block size 128。

社区 INT4

AWQ / GPTQ。同代 LLM：训练 BF16 → 推理 FP8 → 端侧 INT4。

1.2.3 MiniMax H3

权重 BF16。部署时 DiT 可 FP8；VAE 与文本编码器通常保留更高精度。AdaLN 可单独定精度。

扩散步串联，量化要按最终画面评估。流式视频 DiT 同此约束。

1.3.4 算力估计的陷阱

① 稀疏峰值 = 稠密 × 2，宣传数字常用前者。② TF32 只是 FP32 的入口，实际走 Tensor Core。③ 标称频率 ≠ 持续功耗下的实际频率。

1.4 MFU

MFU = 实际 FLOPs/s ÷ 峰值 FLOPs/s。重计算的 FLOPs：HFU 计入分子，MFU 不计。

场景MFU

LLM MoE 训练更低
LLM decode< 5%
DiT 推理天然较高（始终计算受限）
