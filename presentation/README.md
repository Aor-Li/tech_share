# Presentation 工作区

这里保存由已确认正文生成的展示网页及其版本历史。生成时机、版本规则和验收标准见 [`spec/README.md`](../spec/README.md)，项目术语见 [`CONTEXT.md`](../CONTEXT.md)。本工作区只记录版本状态和版本说明，不重复维护流程规则。

## 目录结构

- `versions/vN/index.html`：第 N 个演示版本的单文件报告快照，自包含、可离线打开。
- `versions/vN/NOTES.md`：该版本的元数据、设计意图、优化记录、验收结果和遗留项。

无需安装依赖或执行构建，直接用浏览器打开对应的 `index.html` 即可预览。版本之间不共享外部资源，每个 `index.html` 独立可分享。

## 版本目录模板

新版本从上一版本目录复制而来；`NOTES.md` 使用以下结构：

```markdown

## 版本元数据

| 项目 | 值 |
| --- | --- |
| 内容基线 | <确认提交 hash 或 “无”> |
| 包含章节 | <NN、NN 或 “无”> |
| 快照状态 | 未同步 / 已同步 / 已验收 |
| 来源版本 | v(N-1) 或 — |

## 本版本意图

一句话说明这一版相对上一版要解决什么。

## 优化记录

| 轮次 | 改动 | 触发原因 | 是否更换内容基线 |
| --- | --- | --- | --- |
| 1 | 初始生成 | — | 否 |
```
