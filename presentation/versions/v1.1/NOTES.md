## 本版本意图

v1 的内容和图示结构已经合格，问题在观感：整份报告是浅色底 + 深色页混排，版面留白偏多，若干张 SVG 上有被裁掉或叠在一起的文字。这一版**只改设计与排版，不动信息结构**——换成 Catppuccin Mocha 深色主题，修掉逐页量测出来的显示缺陷，并把图示浪费掉的纵向空间还给正文。43 页构成、36 张图示的内容与页序保持不变（第 5 轮删去导览页，第 10 轮删去理论时间下界页，第 11 轮拆分 1.4 入口页，第 12 轮把 1.4 的通信元语拆成三页，第 13 轮删去 1.5 四问判断卡，第 14 轮重组 02 章结构，第 15 轮精简收尾三页，第 16 轮删去剩下的两页收尾，第 17 轮给三章各加一页要点，现为 43 页、35 张图示）。

## 配色

Catppuccin Mocha，语义变量全部集中在 `:root`，35 张 SVG 通过 `var(--accent)` 等变量取色，因此换色不需要改任何图示标记。

| 用途 | 取色 | 色值 |
| --- | --- | --- |
| 页面底色 | Base | `#1e1e2e` |
| 深色页（封面 / 三张章节页；第 16 轮后不再有收束页） | Crust | `#11111b` |
| 正文 / 次级文字 | Text / Subtext0 | `#cdd6f4` / `#a6adc8` |
| 分隔线 / 强分隔线 | Surface0 / Surface2 | `#313244` / `#585b70` |
| 01 与开场收尾主色 | Teal | `#94e2d5` |
| 02 主色 | Blue | `#89b4fa` |
| 03 主色 | Mauve | `#cba6f7` |
| 代价 / 警示色（全篇统一） | Peach | `#fab387` |

每章一个色相由 `.slide[data-ch^="02"]` 一类选择器切换 `--accent`，现场翻页时能直接从色相判断当前在哪一章；表示「代价、副作用」的 Peach 不随章节变化，保持全篇一致的语义。

打印时整套变量切换到 Catppuccin **Latte**（白底 `#fff`、正文 `#4c4f69`、主色 `#179299` / `#1e66f5` / `#8839ef`），解决 v1 遗留的「深色页打印大量着色」问题。

## 排版调整

| 项目 | v1 | v1.1 | 说明 |
| --- | --- | --- | --- |
| 正文基准字号（1280×720） | 14.5px | 16.3px | `clamp(14px,2.26vh,21px)` |
| 图示取高方式 | `height:100%` + `meet` | `height:auto` 取 viewBox 比例 | 见下 |
| 内容块对齐 | 顶对齐 | `.body` 垂直居中 | 图示与配套卡片作为一组居中 |
| 卡片 | 仅描边 | 描边 + `--panel` 底色 | 深色底上纯描边卡片过弱 |
| 表格 | 表头灰字 | 表头用章节主色 + 偶数行浅底 | 深色底上便于横向读行 |

**图示留白**：v1 里 SVG 以 `height:100%` 铺满容器，而这些图的 viewBox 都偏扁（多为 1000×250 ~ 1000×350），`preserveAspectRatio="meet"` 会在上下各留一条空带。逐页量测的空带高度从 31px 到 244px 不等，中位数约 120px——约占图示区的四分之一。改成 `height:auto` 后图示按自身比例取高，空带归零，省下的纵向空间用于放大正文。
