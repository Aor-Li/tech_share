# TechShare

这是一个面向现场演讲、可离线分享和打印的单文件技术报告项目。

- 在 `references/` 收集创作参考和少量需要核验的事实依据。
- 在 `outline/index.md` 维护报告简报、章节顺序和大纲状态。
- 在 `outline/NN-章节名.md` 逐章规划目标、结论、视觉与制作任务。
- 大纲确认后，在 `content/NN-章节名.md` 逐章迭代正文。
- 用户要求预览或交付时，在 `presentation/versions/vN/` 生成展示网页版本；版本索引见 `presentation/README.md`。
- 代理协作流程统一维护在 `spec/README.md`，项目术语见 `CONTEXT.md`。

项目无需安装依赖、启动服务或执行构建命令。
