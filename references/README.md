# 参考资料区

这里保存两类写作输入：

- **创作参考（`REF-NNN`）**：用于借鉴文章结构、内容覆盖、讲解顺序和图表思路。
- **事实依据（`FACT-NNN`）**：用于核验精确数字、引语、模型或硬件规格、性能对比和高风险强结论。

每份资料在 [`sources.md`](sources.md) 中登记编号、用途和状态。相同材料可以同时承担两种角色，但必须分别说明“借鉴什么”和“核验什么”。

## 目录结构

- `articles/`：文章原文、分章节摘录及来源说明。
- `codes/`：与实践案例相关的代码仓库或固定版本引用。
- `sources.md`：创作参考、事实依据和章节参考对照的统一索引。

默认重新组织文字并重绘图表；直接复用前必须确认许可和署名要求。
