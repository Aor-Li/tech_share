# 按版本管理的展示网页工作区

展示网页从根目录单一 `report.html` 迁移到 `presentation/versions/vN/`，每个演示版本包含一份自包含的 `index.html` 和一份记录内容基线、优化记录与验收结果的 `NOTES.md`，版本索引维护在 `presentation/README.md`。内容基线变化时新开版本，内容基线不变时在当前版本目录内继续优化表达。

这是在“交付物只有一个文件、永远指向最新”的简单性与“可以并排对照设计方案、可以按内容基线回溯已验收版本”的可控性之间作出的取舍。代价是目录层级更深、每次生成都要维护版本元数据和索引，并且版本目录之间存在重复的样式与脚本；换来的是已验收版本不会被后续优化覆盖，展示层的逐步优化也不会与正文确认状态互相纠缠。ADR 0005 确定的分层内容真源不变：展示网页仍然是派生物，只从已确认且已提交的大纲与正文生成，不反向覆盖上游。
