# 交付形态：自包含单文件本地 HTML，非 Artifact

最终交付物是一份**自包含、可离线打开、存入本仓库的单文件 HTML**幻灯：轻量自定义骨架（HTML/CSS/JS + 键盘翻页），关键机制用 SVG + CSS 关键帧做简单分步动画（如 ring all-reduce 数据流、TP 切分、PP 气泡）。全篇用 CSS 变量统一主题，逐章 HTML 片段零成本并入母文件。

正文中文，专业术语（TP/PP/EP、KV cache、all-reduce…）保留英文，首现时中英并注、之后统一英文。

**明确不采用 Artifact 作为最终格式**：作者要求成果能"内部保存"（存入仓库、离线可控）。Claude Artifact 托管在 claude.ai，不满足"本地保存的文件即交付物"这一约束。Artifact 仅可用于开发期的快速预览/分享。

**为什么**：默认路径会倾向于把单文件 HTML 直接发布为 Artifact，但这与"内部保存"的硬约束冲突，且一个反直觉的偏离若不记录，后续可能被"顺手改成 Artifact"。故在此钉死：交付物 = 仓库内的本地 HTML 文件。
